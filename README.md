Este es el repositorio de mi **Portafolio Profesional**, diseñado y desarrollado para mostrar mis habilidades como **Ingeniero en Sistemas y Desarrollador Full Stack**. El sitio web presenta un diseño moderno y premium enfocado en la experiencia del usuario (UX/UI), con transiciones fluidas, soporte multiidioma y un catálogo interactivo de mis proyectos principales.

---

## 🌟 Características Destacadas

- 🌐 **Soporte Multiidioma**: Selector dinámico para cambiar de manera fluida entre **Español** e **Inglés**.
- 🎭 **Animaciones Fluidas**: Desarrollado con **Framer Motion** para lograr transiciones suaves y micro-interacciones interactivas de alta fidelidad.
- 📱 **Diseño 100% Responsivo**: Adaptado perfectamente para una visualización premium tanto en dispositivos móviles como en pantallas ultra-anchas.
- 🎨 **Estilo Moderno**: Construido usando la última versión de **Tailwind CSS v4** y componentes de iconografía nítidos mediante **Lucide React**.
- 🔍 **Galería de Proyectos Interactiva**: Modal avanzado con soporte para capturas de pantalla verticales, funcionalidad de zoom dinámico y arrastre con inercia.

---

## 🚀 Proyectos Destacados en mi Portafolio

1. **FacturaPro (ERP System)**: Sistema de gestión empresarial de nivel empresarial con soporte para facturación electrónica, control de inventario y analíticas detalladas.
2. **BodaDigital (Invitación Interactiva)**: Plataforma digital interactiva para el diseño y RSVP digital de eventos elegantes.
3. **Barber Shop**: Landing page fluida y responsiva para negocios con reserva online.
4. **Gestor de Finanzas**: Aplicación interactiva de finanzas con representación gráfica de gastos.
5. **Buscador de Gifs**: Integración directa con la API de Giphy usando técnicas de Lazy Loading y búsquedas en tiempo real.

## 📦 Instalación y Configuración Local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Kevito11/portafolio-kvaldez.git
   ```

2. Entra al directorio del proyecto:
   ```bash
   cd portafolio-kvaldez
   ```

3. Instala las dependencias necesarias:
   ```bash
   npm install
   ```

4. Inicia el servidor de desarrollo local:
   ```bash
   npm run dev
   ```

5. Para compilar una versión de producción optimizada:
   ```bash
   npm run build
   ```
